The best tools disappear at the moment you need them. They do not ask you to admire them; they shorten the distance between an intention and a finished piece of work.

<!--more-->

I like tools with a small surface area and a deep center. A terminal command that does one thing well. A plain text file that can outlive a platform. A program whose defaults make the next good decision easier.

This is not an argument against ambitious software. It is an argument for software that knows when to step back.
